# Strasse X-Ray для Fabric 1.21.1

`Strasse X-Ray` — отдельный клиентский мод, подсвечивающий цветными рамками руды,
которые уже присутствуют в данных загруженного клиентского мира. Готовый файл:
[`dist/xray_strasse-fabric-1.21.1.jar`](../dist/xray_strasse-fabric-1.21.1.jar).

> Используйте мод в одиночной игре либо на сервере, владелец которого разрешил
> подобную подсветку. Мод не предназначен для обхода серверных ограничений.

## Установка

1. Установите Minecraft **1.21.1**, Fabric Loader и Fabric API.
2. Скопируйте `xray_strasse-fabric-1.21.1.jar` в папку `mods` игрового профиля.
3. Запустите игру и откройте мир.
4. Нажмите **X**, чтобы включить или выключить подсветку.

Клавиша полностью настраивается штатно: **Настройки → Управление → Назначение клавиш →
Strasse X-Ray**.

## Что подсвечивается

| Руда | Цвет рамки |
|---|---|
| Уголь | серый |
| Железо | бежево-оранжевый |
| Медь | оранжевый |
| Золото и незерское золото | жёлтый |
| Редстоун | красный |
| Лазурит | синий |
| Алмазы | бирюзовый |
| Изумруды | зелёный |
| Незер-кварц | белый |
| Древние обломки | фиолетовый |

Учитываются обычные и глубинные варианты руд. Рамки рисуются поверх блоков и видны
сквозь окружающий рельеф.

## Технические параметры

- радиус поиска по горизонтали: **24 блока**;
- радиус по вертикали: **16 блоков**;
- повторное сканирование: раз в **12 тиков**;
- защитный предел: **4096 рамок**;
- результаты поиска кэшируются по типу блока, чтобы не разбирать идентификатор
  каждого блока при каждом проходе;
- мод полностью клиентский (`environment: client`) и ничего не отправляет серверу.

Исходный Gradle-проект находится в [`mods/xray-fabric-1.21.1`](../mods/xray-fabric-1.21.1/):

```bash
cd mods/xray-fabric-1.21.1
./gradlew build
```

В изолированной среде тот же production-jar собирается оффлайн с последующим
remap в Fabric intermediary:

```bash
./tools/offline-build/fetch-toolchain.sh
python3 tools/offline-build/build.py --template xray-fabric-1.21.1 --out dist
python3 tools/offline-build/verify.py \
  --report tools/offline-build/xray-api-usage.txt \
  dist/xray_strasse-fabric-1.21.1.jar
```

## Ограничение anti-xray

Сервер определяет содержимое отправляемых клиенту чанков. Если серверный anti-xray
заменяет скрытую руду камнем до отправки, клиент получает состояние камня; этот мод
тоже увидит камень. Он подсвечивает реальные состояния блоков, уже полученные
клиентом, и не пытается извлекать закрытые серверные данные или использовать
уязвимости.
