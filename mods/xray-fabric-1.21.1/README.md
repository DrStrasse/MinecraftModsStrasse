# Strasse X-Ray — Fabric 1.21.1

Клиентская подсветка руд для одиночной игры и серверов, где такие инструменты
разрешены. Нажмите **X** для переключения; клавишу можно изменить в штатном меню
управления Minecraft.

Мод сканирует только состояния блоков, уже полученные клиентом. Он не извлекает
скрытые серверные данные и не обходит anti-xray.

## Сборка

```bash
./gradlew build
```

Требуются Java 21, Minecraft 1.21.1, Fabric Loader и Fabric API.
Подробная документация: [`../../docs/12-xray.md`](../../docs/12-xray.md).
